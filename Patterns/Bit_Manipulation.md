# Bit Manipulation 

### XOR
```
Property --->
- X ^ X = 0
- X ^ 0 = X

- (a ^ b) = (b ^ a)
- (a^b)^c = (a^c)^b = a^b^c
- a^b = c , then a^c = b , b^c = a

Use When --->
Pairs Cancel + Odd-One-Out -> Think XOR
```
