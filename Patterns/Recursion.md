# Recursion 

## 3 Question Trick to Identify If Problem Can be Solved with Recursion 

> __Primary Question --->__
> 
__Can I solve the problem by solving a smaller version of the same problem?__

> __Is there a smaller input/subproblem?__

> __After solving the smaller problem, can I do a small amount of work to finish the current problem?__

> __Is there a clear base case?__


### Pattern 
> __Current problem = small work + same problem on a smaller input__
