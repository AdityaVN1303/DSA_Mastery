# Basic Array Techniques 

### 1. Extreme Tracking 
```
Maintain the Best K Value while Traversing Once

TC - O(N)
SC - O(1)
```

### Running Min/Max
```
Need Minimum/ Maximum Value Seen So Far

Use *(min/max_element()) function 

TC - O(N)
SC - O(1)
```

### Counting / Filtering 
```
Need Count or Collect Elements Satisfying a Condition

if condition : count++

```

### Linear Search
```
O(N) Search in Unsorted Array 
```

### Reverse 
```
use reverse() function to reverse array in place in O(N) TC
```

### Swap / Rearrange 
```
use swap() function to swap in-place
```

### Basic Rotation 
```
Use reverse() function based on K.

Rotates array in O(N) TC and O(1) SC
```
