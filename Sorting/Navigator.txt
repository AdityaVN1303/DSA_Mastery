Sorting Problems ---> 
- Bubble Sort - Swap Every Iteration 
- Selection Sort --- Choose Smallest Swap Once
- Insertion Sort --- Best Case - O(N) - If Already Sorted , while Loop Runs 0 Times
- Recursive Bubble Sort - Flag Optimization (Gives O(N) in Best Case)
- Recursive Insertion Sort 
- Recursive Selection Sort 
- Merge Sort --- Divide and Merge 
- Quick Sort --- Pivot Selection + Hoare Partition Scheme (Two Pointer)
