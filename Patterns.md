# Patterns

```
Hashing ---
- Frequency Count - Hashmap / array Hash / Inplace Modulo Hashing

Sorting ---
- Sort + Linear Scan (Single Pass)

Math Formulae ---
- Count Digits - log10(n) + 1

Math Patterns ---
- Divisor Pairs / √n Iteration (i , n/i)
- Digit Manipulation (Extraction/Removal/Sum/Product/Count/Frequency of Digits , Transformed/Reverse Number , Palindrome Check)
- Euclidean Algorithm
```

# Triggers

```
Factors of Number ---> Divisor Pair
GCD/LCM ---> Euclidean Algorithm
Process Digits of Number ---> Digit Manipulation
Frequency/Occurences ---> Frequency Hashing
Need Grouping/Order to Expose Relationships ---> Sorting + Linear Scan
```
